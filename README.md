# JavaScript REST API CRUD Demo

A simple frontend project demonstrating how to integrate a web application with a REST API using **HTML, CSS, and JavaScript**.

This project uses the public REST API provided by [restful-api.dev](https://restful-api.dev/) to demonstrate CRUD operations.

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API
- JSON
- Git & GitHub
